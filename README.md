# Quiz App — платформа для интерактивных квизов

Веб-приложение для проведения квизов в реальном времени с поддержкой WebSocket, лидербордом и историей игр.

---

## Стек технологий

### Backend

| Технология | Назначение |
|------------|------------|
| Python 3.11+ | Язык программирования |
| FastAPI | Веб-фреймворк (REST API, WebSocket) |
| SQLAlchemy | ORM для работы с базой данных |
| PostgreSQL | Реляционная база данных |
| Pydantic | Валидация данных и схемы |
| Uvicorn | ASGI сервер |

### Frontend

| Технология | Назначение |
|------------|------------|
| HTML5 | Структура страниц |
| CSS3 | Стилизация и дизайн |
| JavaScript | Клиентская логика, WebSocket |
| WebSocket API | Реальное время (вопросы, ответы, лидерборд) |
| Fetch API | HTTP запросы к REST API |

**Основные возможности приложения**

- Пользователи могут зарегистрироваться в системе, войти в аккаунт и восстановить пароль.

- Организатор может создавать новые квизы, заполняя их вопросами с вариантами ответов, загружать изображения к вопросам, а также редактировать и удалять существующие квизы. Все квизы можно экспортировать в JSON файл для бэкапа, и импортировать обратно из JSON.

- Организатор создаёт игровые сессии, на каждую из которых генерируется шестизначный код. В панели активных сессий отображаются все созданные комнаты.

- Участник после входа в систему вводит полученный от организатора код комнаты. Система проверяет правильность кода, существование комнаты, наличие свободных мест и то, не началась ли уже игра. Если всё хорошо, то участник попадает в комнату ожидания.

- Когда организатор начинает сессию, все участники из комнаты ожидания попадают в игру.

- Вопросы показываются всем участникам одновременно в реальном времени. Каждый вопрос сопровождается таймером. Вопросы могут быть только текстовыми или иметь изображения. Участник выбирает один или несколько вариантов ответа в зависимости от типа вопроса.

- После завершения всех вопросов игроки видят финальный лидерборд с итоговыми местами. Привычислении мест учитываются баллы и общее время ответа - если ничья, то выше будет тот, кто ответил быстрее. 

- Все результаты игры сохраняются в историю, которая доступна участнику в личном кабинете. В истории отображается список всех пройденных квизов с количеством правильных ответов и набранными баллами. При нажатии на любой квиз открывается детальная страница, где показаны все вопросы с отметками о правильности ответа, а также указано, какой вариант выбрал игрок и какой был правильным.

- В настройках профиля пользователь может изменить своё имя, почту и пароль. Также доступен выход из аккаунта.

## Запуск проекта

```bash
git clone https://github.com/aaxelf/quiz_app.git
cd quiz_app

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

python init_db.py
python run.py
```
